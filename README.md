# hxwl-06 显微镜玻片观察 · 多倍率视野复现台

样本、低 / 中 / 高倍率视野、独立会签、第三人复现与版本化更正记录台。

## 技术栈

React 19 + Vite 7 + TypeScript（strict）+ 原生 CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 业务规则

- **多倍率视野**：每个样本自动建立 100×（低倍）、400×（中倍）、1000×（油镜高倍）三个视野。
- **登记字段**：染色批次、坐标、重点结构、染色判断、视野描述、原观察者。
- **单一有效结论**：同一视野同一时刻只有一条有效结论（`activeVersionNo` 指向）。
- **两名独立会签**：需两名与原观察者不同的观察者，勾选「已在同倍率下独立观察」后签署；
  原观察者不得自签，同一人同一轮不得重复签署。
- **第三人复现**：任一会签者就结构或染色判断不同意，视野转「争议」；
  由未参与原观察与会签的第三人复现，系统自动比对并**指出差异字段**（重点结构 / 染色判断）。
  - 复现与原结论不同：以复现值新建版本，旧版本整体保留并标记被取代，新版本重新会签。
  - 复现支持原结论：不开新版本，另起一轮重新征集两名独立会签。
- **冻结**：三个倍率全部两人会签确认后样本冻结；冻结后不能新增或修改视野。
- **更正**：已冻结视野只能「更正并新建版本」，必须填写更正原因；
  旧值完整保留（置灰展示），新版本重新走会签，样本解冻。
- **刷新一致**：数据持久化在 localStorage（带版本号），刷新后样本、视野、会签与版本保持一致。

## 分层结构（数据 / 判断 / 保存 / 页面分离）

```
src/
├─ types.ts                 领域类型，不含逻辑
├─ domain/
│  ├─ rules.ts              判断层：纯函数业务规则（登记/会签/复现/冻结/更正/统计）
│  └─ rules.test.ts         规则端到端断言（32 项）
├─ data/
│  ├─ seed.ts               数据层：演示种子（经规则函数构造，保证合法）
│  └─ storage.ts            保存层：localStorage 读写，可替换为 IndexedDB / 后端 API
├─ state/
│  └─ useStation.ts         控制器：深拷贝 → 调规则 → 保存 → 提交，向页面暴露动作
└─ components/              页面层：Header / MetricsBar / SampleList / SampleDetail / FieldCard
```

判断层是无副作用的纯函数，不依赖 React 与存储；存储层可整体替换而不触碰规则。
