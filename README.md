# hxwl-06 显微镜玻片多倍率视野复现台

在原玻片观察页基础上扩展的多倍率视野复现台：每个样本建立低 / 中 / 高三档倍率视野，
登记染色批次、载物台坐标、重点结构与观察者；两名观察者独立会签，不一致转第三人复现；
确认后冻结，更正写原因、建版本、留旧值；刷新后全部状态一致。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式）+ 原生 CSS，持久化使用 localStorage，
测试使用 Vitest。

## 本地运行

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5106
npm test           # 规则层 + 持久化单元测试
npm run typecheck  # 严格类型检查
npm run build      # 生产构建
```

## 业务规则

1. **三档倍率视野**：每个样本分别建立低倍 100× / 中倍 400× / 高倍 1000×（油镜）视野，
   每档倍率唯一；登记染色批次、载物台坐标（x/y/z μm）、重点结构与原观察者。
2. **同一视野一条有效结论**：任一时刻每视野至多一条 `confirmed` 结论。
3. **两名独立观察者会签**：结论提交后由两名非原观察者各自独立录入自己的结构与染色判断；
   原观察者不得自签、每人限签一次。系统逐项比对，两人均一致才确认。
4. **不一致转第三人复现**：会签中结构或染色任一项不一致即转 `disputed`，
   系统指出差异字段（重点结构 / 染色批次）与具体会签人；第三人须独立于原观察者与前两名会签人，
   可裁决维持原结论或按复现结果更正字段后确认，裁决全程留痕。
5. **确认冻结**：三档视野结论全部确认后样本方可冻结，样本信息、倍率集合与有效结论锁定。
6. **更正留旧值**：冻结（或任何已确认）结论的更正必须填写原因，旧版本置 `superseded`
   并完整保留旧值，新版本号递增、从草稿重新走两人会签，版本链可追溯。
7. **刷新一致**：所有变更即时写入 localStorage，刷新后样本、视野、会签与版本链保持一致；
   数据损坏时回退内置演示数据。

## 分层结构（数据 / 判断 / 保存 / 页面分离）

| 模块 | 职责 |
| --- | --- |
| `src/types.ts` | 领域模型：样本、视野、结论版本、会签、第三人复现记录 |
| `src/rules.ts` | **纯函数判断层**：会签资格、逐项一致性、争议转复现、差异字段、版本更正、冻结条件（不依赖 React / DOM） |
| `src/storage.ts` | **保存层**：localStorage 读写、损坏回退、演示种子数据 |
| `src/store.ts` | **编排层**：`useBenchStore` 组合数据 / 判断 / 保存，暴露页面动作与操作反馈 |
| `src/components/`、`src/App.tsx` | **页面层**：样本面板、倍率视野卡片、会签 / 复现 / 更正表单与版本时间线 |
| `src/rules.test.ts`、`src/storage.test.ts` | 规则与持久化的单元测试（22 个用例） |
